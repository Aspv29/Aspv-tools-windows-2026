# Quick Start - Top Rated Firmware Page

## Inicio Rápido

### 1. Instalar dependencias
```bash
cd mvps-hacking-mods
npm install
```

### 2. Iniciar el servidor
```bash
npm start
```

### 3. Acceder a la página

Abre tu navegador y visita:

**Página Principal:**
- http://localhost:3000

**Página Top Rated (Directa):**
- http://localhost:3000/top-rated.html
- http://localhost:3000/top-rated

**Desde la página principal:**
- Haz clic en el botón dorado "🏆 Ver Top Rated Firmware" en el header
