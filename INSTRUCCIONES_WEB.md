## 🌐 Cómo Acceder a la Página Web

### Opción 1: Servidor Web en Ejecución (Activo Ahora)

El servidor web ya está corriendo y puedes acceder a la página en:

```
http://localhost:3000/mejor_calificacion.html
```

### Opción 2: Abrir Directamente en el Navegador

Simplemente abre el archivo `mejor_calificacion.html` con cualquier navegador web:

```bash
# En Linux
xdg-open /vercel/sandbox/mejor_calificacion.html

# En macOS
open /vercel/sandbox/mejor_calificacion.html

# En Windows
start /vercel/sandbox/mejor_calificacion.html
```

O arrastra el archivo directamente a tu navegador.

### Opción 3: Iniciar tu Propio Servidor Web

Si necesitas reiniciar el servidor:

```bash
cd /vercel/sandbox
python3 -m http.server 3000
```

Luego accede a: `http://localhost:3000/mejor_calificacion.html`
