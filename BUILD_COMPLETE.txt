🚀 CÓMO USAR

Para Windows (Recomendado):
   1. Copia el archivo dist/ASPVTools a tu PC Windows
   2. Haz clic derecho → "Ejecutar como administrador"
   3. ¡Disfruta de todas las funciones!

Para Linux (Modo Demostración):
   1. Ejecuta: ./dist/ASPVTools
   2. Nota: Funcionalidad limitada (diseñado para Windows)

Compilar en Windows:
   1. Instala Python 3.8+ y PyInstaller
   2. Ejecuta: build_exe.bat o build_exe.ps1
   3. El ejecutable estará en dist/ASPVTools.exe
